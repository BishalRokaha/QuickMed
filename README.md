# 🩺 QuickMed - Online Medicine Delivery Platform

A modern, full-featured online medicine delivery and healthcare products platform built with React, Vite, Tailwind CSS, and TypeScript, focused on speed, scalability, and clean UX.

---

## 🚀 Features

- 💊 Medicine Browsing – Explore medicines and healthcare products with a clean UI 
- 🔍 Smart Search – Quickly find medicines and products
- 🛒 Cart System – Add, update, and manage items seamlessly  
- 🧾 Order Flow (Planned) – End-to-end order placement experience 
- ⚡ Fast & Optimized – Built with Vite for blazing-fast performance
- 📱 Responsive Design – Fully responsive across mobile, tablet, and desktop
- 🎨 Modern UI – Powered by Tailwind CSS and shadcn/ui 


---

## 🛠️ Tech Stack

- **Frontend**: React (Vite, TypeScript, Hooks)
- **Styling**: Tailwind CSS + shadcn/ui 
- **Deployment**: Vercel (planned) 
- **State Management**: React Hooks & Context (extensible)  

---

## 🎯 Why This Project?

This project was built to:
- Practice building a real-world healthcare product
- Strengthen frontend fundamentals using React + TypeScript
- Learn scalable project structure with Vite
- Implement modern UI systems using Tailwind & shadcn
